# Veolia VRSI 0.2.0 — facturi, preț pe m³, contoare din factură

> Execuție inline, cu TDD. Commit-urile le face utilizatorul.

**Scop:** din PDF-ul fiecărei facturi se citesc tarifele, cantitățile facturate și **toate contoarele** (seria se citește din factură, nu e fixată nicăieri; un loc poate avea 1, 2 sau mai multe contoare). Integrarea expune prețul pe m³ și consumul fiecărui contor, cu statistici lunare.

**Spec de bază:** `docs/superpowers/specs/2026-11-24-veolia-design.md`. Ce se schimbă față de el:
- endpoint nou permis: `download-invoice` `{clientCode, invoiceNumber}` → `content.InvoiceContent` (PDF base64);
- PDF-ul nu se salvează; add-on-ul păstrează în `/data/invoices.json` doar cifrele extrase, după numărul facturii;
- cel mult 6 facturi noi descărcate la o actualizare, de la cea mai nouă.

## Formatul facturii (pagina 2, „DETALII FACTURĂ”)

```
Perioada de facturare: 29.09.2026 - 28.10.2026
Serie contor Index nou Index vechi Consum Stabilit prin Motiv* Data
22AA000001 419 408 11 citire 28.10.2026
Serie contor condominiu Index nou Index vechi Consum Stabilit prin Motiv* Data
I23AA000009 3.355 3.253 102 citire 28.10.2026
Servicii facturate Cantitate(mc) Tarif (lei) Valoare (lei) Cota TVA TVA (lei) Total (lei)
Servicii alimentare cu apă potabilă (mc) 14,89 7,26 108,09 11% 11,89 119,98
Servicii canalizare apă uzată (mc) 11,91 10,48 124,83 11% 13,73 138,56
Servicii colectare şi transport apă meteorică (mc) 0,00 10,48 0,00 11% 0,00 0,00
Contravaloare servicii             232,92 25,62 258,54
Data următoarei citiri: 26.11.2026
Interval transmitere autocitiri: 21.11.2026 - 25.11.2026
```

Numere în format românesc: `3.355` = 3355, `14,89` = 14.89.

## Contract bridge → integrare

`accounts[cod_client]["invoice_details"] = {număr_factură: detalii}`, unde detalii:

```json
{
  "invoice_number": "VAS000000002", "issued": "2026-11-03", "due": "2026-11-18",
  "period_start": "2026-09-29", "period_end": "2026-10-28",
  "meters": [{"serial": "22AA000001", "kind": "individual", "index_new": 419, "index_old": 408,
              "consumption": 11, "method": "citire", "reason": null, "date": "2026-10-28"}],
  "services": {"apa": {"label": "...", "quantity": 14.89, "tariff": 7.26, "value": 108.09,
                       "vat_rate": 11, "vat": 11.89, "total": 119.98}, "canalizare": {...}},
  "total_without_vat": 232.92, "vat": 25.62, "total": 258.54,
  "next_reading": "2026-11-26", "reading_window": ["2026-11-21", "2026-11-25"]
}
```

`kind`: „Serie contor” → `individual`, „Serie contor condominiu” → `condominiu`, alt titlu → slug-ul textului de după „Serie contor”. Servicii: `apa`, `canalizare`, `apa_meteorica`, altfel slug.
